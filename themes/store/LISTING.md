below claims behaviour a theme can't have; every extension claim matches

## Item 1 — SEO Bandwagon · Neon Night

**Name** (45 char max)

```
SEO Bandwagon — Neon Night
```

**Short description** (132 char max)

```
Dark Bandwagon pink on midnight navy, with a neon city skyline behind every new tab.
```

**Category:** Themes → Dark & Black

**Detailed description**

```
The dark half of the SEO Bandwagon pair. Bandwagon pink (#F53796) on midnight
navy (#000022), with a neon city skyline sitting behind your new tab, tuned so
the sky — not the buildings — falls behind Chrome's search box.

WHAT YOU GET
- Frame, tab strip, toolbar and omnibox in the Bandwagon palette
- A new-tab wallpaper that stays put and never stretches, at any window size
  (Chrome only — browsers that replace the new tab page with their own, such
  as Brave, show the frame and toolbar colours but not the wallpaper)
- Matching pink accents on the active tab, links and buttons

PREFER LIGHT?
Install SEO Bandwagon — Neon Day instead:
https://chromewebstore.google.com/detail/ldifldabjbffldoekbebpickddaiiggm
Chrome runs one theme at a time, so installing either replaces the other.

WORKS WITH THE SEO BANDWAGON EXTENSION
If you also run our free extension, its popup, side panel and options page can
match this theme (Appearance → Night). The extension is an on-page SEO toolkit
that runs entirely in your browser: a 0–100 score with an A–F grade and four
sub-scores, page meta with a search-result preview, Core Web Vitals, heading,
link and image audits, link check, indexability, hreflang, rendering, structured
data, and a results overlay on Google's own search pages. No account required
for any of it.

The theme collects nothing. It has no code, no permissions and no network
access — it is a colour map and a handful of images.
```

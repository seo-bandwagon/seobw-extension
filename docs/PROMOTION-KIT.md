## 150 words

SEO Bandwagon is a free, no-account Chrome extension that audits the page you
are on. One click gives a 0 to 100 score with an A to F grade, four sub-scores
(Meta, Content, Links, Tech) and the specific issues to fix. It also covers:
- page meta with a search-result preview
- Core Web Vitals
- headings, links and images, each exportable as CSV

Six deeper checks sit behind it:
- Link Check probes every link and groups them by status.
- Indexability shows the redirect chain, response headers and X-Robots-Tag, and
  gives a verdict.
- Hreflang validates the tags and their return links.
- Rendering compares the raw HTML with the rendered page and can reload as
  Googlebot.
- Structured Data validates JSON-LD, Microdata and RDFa against rich-result
  requirements.
- On Google's own results, a stats bar sits under each result, and an export
  captures each result's description, date, rating and breadcrumb.

Night and Day themes included.

## Feature list (1.6.1)

- One-click page score (0 to 100, A to F) with four sub-scores and the issues to fix
- Page meta and a search-result preview; Core Web Vitals (LCP, INP, CLS, FCP, TTFB)
- Headings, links and images, with on-page highlighting and CSV export; nofollow, UGC and sponsored links surfaced
- Link Check: every link probed and grouped by status, broken links highlighted, CSV
- Indexability: redirect chain, response headers, X-Robots-Tag, verdict; trace any URL
- Hreflang: tag validation plus return-tag checks
- Rendering: raw HTML vs. rendered DOM, and a "View as" user-agent switcher
- Structured Data: JSON-LD, Microdata and RDFa, with rich-result eligibility
- Google results overlay: stats bar per result, a 19-column CSV export, "People also ask" copy, location simulator
- Search Console helpers: open a query in Google (or privately) from the Queries tab; percent-change badges in compare mode
- Right-click tools menu: Search Console, PageSpeed Insights, Rich Results Test, Wayback Machine, site: search, sitemap.xml, robots.txt
- Local-SEO citation checks against 40 directories (NAP extraction and match scoring)
- Night / Day / Auto appearance, with two matching Chrome themes
- Local-first; an optional free account syncs captures

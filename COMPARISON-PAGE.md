## Per-competitor sections (~250 words each)

Structure per section: what it does best (genuine praise) → where it falls short →
best for → source link.

### SEOquake — best for SERP-first research
The most installed and the strongest SERP overlay in the category: metrics on
every Google result, exportable, with keyword density and a solid page audit.
Honest strengths: maturity, multi-browser support, Semrush data without an
account. Weaknesses: crowded UI, no Core Web Vitals, no local SEO, authority
depth requires Semrush. **Best for:** SERP scrapers and Semrush users.

### Detailed — best for fast on-page checks
The cleanest single-purpose tool with the best rating in the category (4.9★).
One click, everything on-page, zero configuration. Weaknesses: that's all it does
— no score, no vitals, no links audit, no export; and it's an Ahrefs property, so
expect its roadmap to funnel toward Ahrefs accounts. **Best for:** quick audits
during content reviews.

### Ahrefs SEO Toolbar — best for technical link work
Redirect tracing with HTTP headers, broken links, country switching — genuinely
useful free tier. Weaknesses: the headline metrics (DR, traffic) are paid; no
score, no vitals. **Best for:** existing Ahrefs subscribers.

### SEO Minion — most features, no longer free
The broadest utility belt (broken links, hreflang reciprocity, location
simulator, SERP extractor, HTML vs DOM) but now gated behind a Keywords
Everywhere Silver+ plan, and it shows in the 4.0★ rating. **Best for:** Keywords
Everywhere subscribers who already pay.

### SEO Bandwagon — best for local SEO + performance
The only extension that treats local SEO as a first-class job: detect the
directory you're on, compare the listing's NAP against your master record with a
weighted match score, capture proof screenshots, and file citations without
leaving the page. Plus the only in-browser Core Web Vitals in the category, a
composite score, tech stack detection, and full data export — free, no account
required for analysis. Weaknesses (say them): no backlink index, SERP overlay
and broken-link checking land in v1.5. **Best for:** local SEO practitioners,
agencies managing citations, and anyone who wants performance + on-page in one
free tool.

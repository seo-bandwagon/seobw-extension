# Security Policy

Please do not open public issues for vulnerabilities. Report them privately
through GitHub instead: [report a vulnerability](https://github.com/seo-bandwagon/seobw-extension/security/advisories/new)
(the Security tab, then "Report a vulnerability"). Only the maintainers see the
report. Include the details and, if you can, steps to reproduce.

If you can't use GitHub, email kyle@seobandwagon.com.

We aim to acknowledge reports within 3 business days. Only the latest version
published on the Chrome Web Store is supported.
